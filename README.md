# runexe-dependencies

Windows dependencies (fonts, runtimes, redistributables) that RunExe can install into a capsule.

This catalog is read by [RunExe](https://github.com/hazem-hamsho/RunExe). Each entry is a YAML manifest; `index.yml` lists the available entries.

Report problems on the [RunExe issues page](https://github.com/hazem-hamsho/RunExe/issues).
